# ОРБИТА 0.5.4 — подготовленная авторизация

Это тестовый ARM64 debug APK, не релиз и не завершённая облачная интеграция. minSdk 24; Android 7–13 и отсутствие Google на реальных устройствах не проверены. Сборка из `codex/orbita-stage-3b-auth`, версия 0.5.4+5.

Сначала владелец читает [пакет на GitHub](https://github.com/primord1aal/Ordita-0.1v/blob/codex/orbita-stage-3b-auth/docs/STAGE_3B_APPROVAL_PACKAGE.md). В этой контрольной точке не требуется устанавливать APK, вводить пароли или выполнять SQL. Облачная схема/Auth ещё не менялись.

В артефакте CI `ORBITA-0.5.4-auth-preparation-apk` находятся APK, SHA256SUMS, эта инструкция, справочная копия пакета и документ о Free. Ссылки на исходники внутри справочной копии рассчитаны на просмотр пакета в GitHub. Нужен вход в GitHub, хранение 14 дней.

Будущая установка и интеграционные действия выдаются отдельно, по одному шагу, после согласования. При несовпадении debug-подписи не удалять предыдущую тестовую установку без отдельной инструкции: это сбросит её локальные данные/разрешения.

Диагностика API, сети, уведомлений и GPS сохраняется. Долгие прогоны под блокировкой не считаются проверенными. Нет полноэкранного окна заказа поверх блокировки, серверного Push, карт, заказов или настоящей линии.

При будущих испытаниях не передавать пароли, Access/Refresh Token или сырые Auth-ответы в чат. Диагностический журнал API копирует только разрешённые поля. Результат аппаратного secure storage/входа/refresh должен быть подтверждён на Tecno отдельно от искусственных тестов.
