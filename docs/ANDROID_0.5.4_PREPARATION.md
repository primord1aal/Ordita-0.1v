# ОРБИТА 0.5.5 · сборка 7 — карта и адреса

Первая часть этапа 3В, ветка `codex/orbita-stage-3v-maps` от принятой сборки 6. Тестовый ARM64 debug APK, минимум Android 7 / API 24. Android 7–13 и устройство без Google-сервисов физически не проверены.

Имя артефакта и файла исторически осталось `ORBITA-0.5.4-auth-preparation-apk` / `ORBITA-0.5.4-auth-preparation.apk`, поскольку существующий workflow не менялся. **Внутри новая версия 0.5.5 / сборка 7.** Скачивать из успешного `verify` новой ветки для переданного SHA, а не из прежнего Preview/Apply. Нужен вход в GitHub; хранение 14 дней. В архиве есть SHA256SUMS.

Это действующая инструкция к текущему APK. `STAGE_3B_APPROVAL_PACKAGE.md` в архиве — исторический справочник подготовки авторизации, не команда повторять миграцию. Для этой APK Supabase, Auth-настройки, аккаунты и миграционные SHA не меняются.

Подпись debug может отличаться от установленной. При несовпадении Android не обновит приложение поверх прежнего. Удаление старой установки сбросит локальный вход, разрешения и ключ карт; серверный тестовый аккаунт сохранится. **Не удалять старую установку автоматически.** Стабильный ключ подписи — отдельная задача.

## Что проверить в новой части

Пассажир видит карту, два поля «Откуда»/«Куда» и подсказки настоящих адресов после настройки Geoapify. Значок карты у каждого поля открывает выбор точки. При ошибке обратного поиска точка сохраняется; адрес не выдумывается. Если ключ карт ещё не задан, доступен ручной текст, карта честно обозначена как неподключённая.

В debug APK: **Профиль → Проверка устройства → Расширенная диагностика → Настройка карт**. Вставить API-ключ своего бесплатного проекта [Geoapify](https://myprojects.geoapify.com/) в скрытое поле и сохранить. Он хранится только в secure storage этого устройства, отдельно от входа. Не передавать ключ в чат и не использовать здесь пароли/ключи Supabase. GitHub Secrets/Variables/Environment для этой настройки менять не нужно.

Выбрать несколько знакомых адресов Чика и Прокудского, проверить оба поля, ручной выбор точки, Back без подтверждения, крупный шрифт/поворот, потерю и восстановление сети. Выбранный адрес и вкладка сохраняются при обычной перепроверке неизменных прав. Подробности и условия Free — [инструкция этапа 3В](https://github.com/primord1aal/Ordita-0.1v/blob/codex/orbita-stage-3v-maps/docs/ANDROID_0.5.5_MAPS.md).

Прошлые проверки авторизации +5 и интерфейса +6 уже подтверждены владельцем. Не нужно заново проходить каждый серверный сценарий. Новая карта +7 требует отдельного результата на устройстве: модельные тесты не проверяют реальную адресную базу или доступность Geoapify в сети владельца.

Создание заказов, маршруты/цены, рабочая водительская карта и серверный Push не добавлены. Позиция пассажира автоматически не запрашивается. Длительная геолокация 10/30/60 минут остаётся отдельной задачей; [чек-лист HiOS](https://github.com/primord1aal/Ordita-0.1v/blob/codex/orbita-stage-3v-maps/docs/ANDROID_STAGE_2.md). Этап 4 не начат.
