AUTH 0.2

Проверка связи с Supabase

Эта отдельная тестовая страница проверяет настоящий вход и права пользователя. Она не заменяет нашу версию 0.1 и пока не создаёт поездки.

Параметры подключения ещё не заданы.

1. Подключаем тестовый сервер

Вводить можно только Project URL и Publishable key с префиксом sb_publishable_. Они предназначены для браузерного приложения. Секретные ключи не вводи.

Настройки подключения сохраняются только в браузере этого телефона. Пароль здесь не вводится.

2. Вход в «Орбиту»

Введи тестовые данные, созданные в Supabase Authentication → Users.

Права администратора—

Чтение тестовой базы выполнено с правами вашего аккаунта, не через секретный ключ.

Зарегистрировано водителей—
Создано заказов—

Это тест с вымышленными пользователями и заказами. Не вводи сюда личные данные пассажиров или настоящих водителей. Пароль базы данных, sb_secret_... и service_role сюда вводить нельзя.
