# Inter в приложении

Источник: официальный релиз [Inter 4.1](https://github.com/rsms/inter/releases/tag/v4.1), архив `Inter-4.1.zip`.
В комплект включены статические TTF Regular, Medium, SemiBold, Bold с кириллицей.
Лицензия: SIL Open Font License 1.1, файл [OFL.txt](OFL.txt). Текст также зарегистрирован через Flutter `LicenseRegistry` для экрана лицензий приложения. Шрифт загружается только из локальных ресурсов.
