## Что исправлено

- Один `BrandHeader` внутри SafeArea: высота 74 dp при ×1, логотип 42×42, типографика водительского заголовка по CSS.
- Ползунок 64 dp, бегунок 50×50, внешние отступы 18 dp. OFF слева, ON справа; в обычном режиме недоступный OFF с подписью «Не на линии», без приглашения к неработающему действию. Обработка жестов, отмены, ошибок и поздних ответов сохранена.
- Карта получает оставшуюся высоту после измерения шапки, ползунка и панели. На 390×844 при ×1 панель и навигация видны одновременно без прокрутки страницы. При увеличении текста содержимое прокручивается.
- Компактная панель с индикатором, «Заказы» / «Активных поездок нет» и пиктограммой маршрута; в изолированном ONLINE — «Предложения» / «Новых предложений пока нет».
- В водительском режиме одна неактивная GPS-кнопка 48×48 справа снизу, масштабирование карты жестами. Поведение пассажирских кнопок по умолчанию сохранено; фиктивной геопозиции нет.
- Навигация «Линия | Поездки | Профиль», иконка карты и высота 73 dp при ×1 без системного нижнего отступа.
- В предложении заголовок и таймер на одной строке, тонкая полоса времени, общий блок адресов с пиктограммами, кнопки высотой 52 dp в пропорции 1:1.2.
- При ×3.2 атрибуции полностью доступны над нижним меню, адресные поля пассажира достижимы прокруткой. Системный TextScaler не ограничен.
- Технические пояснения убраны с пользовательских экранов. Выбор искусственного сценария находится во внутренней панели по долгому нажатию на логотип из диагностического представления; штатный экран предложений не имитирует.

### Установка на Tecno KL7

1. Скачать APK по ссылке в итоговом сообщении, сверить SHA-256. При передаче по USB не переименовывать расширение.
2. До обновления сравнить сертификат уже установленного `ru.orbita.taxi.dev` с указанным выше (`apksigner verify --print-certs` для обоих APK). Использована штатная debug-подпись, автоматически созданная в новой среде; совпадение с прежней подписью неизвестно. Постоянный production-ключ не создавался, прежний ключ не заменялся.
3. Только при совпадении сертификата и допустимом повышении версии открыть APK штатным установщиком Android, разрешив установку из выбранного источника. Вариант для заранее разрешённого USB-устройства: `adb install -r ORBITA-0.5.7+9-arm64-debug.apk`.
4. Если Android отклоняет подпись или версию, сохранить сообщение ошибки и остановиться. Не удалять старое приложение, не очищать данные и не обходить отказ принудительным понижением. Для совместимого обновления нужна сборка с прежним согласованным ключом.

Установка и запуск на физическом Tecno в этой среде не выполнялись.

## Оставшаяся приёмка

Окончательное визуальное решение принимает владелец по пяти сравнениям и приложению на Tecno KL7. Физические Android 14, TalkBack, настоящий Geoapify и совместимость подписи с ранее установленным APK в этой среде не проверялись. Наличие собранного APK само по себе не подтверждает эти сценарии.
