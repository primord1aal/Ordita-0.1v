# Орбита 0.5.9+11 — тестовый ARM64 APK

Сборка для Tecno KL7, Android 7.0+; package ru.orbita.taxi.dev. Установить обновлением поверх 0.5.8, не удалять приложение и не очищать данные. Сертификат прежний; сессия и заданный на телефоне ключ карты сохраняются.

Исправлены отдельная выдвижная адресная панель, поиск над клавиатурой, короткие адреса и обратный поиск точки без вывода координат. Подробный светлый слой карты используется в обеих темах. GPS запрашивает разовую свежую позицию; разрешите геолокацию при использовании приложения. После системного разрешения и проверки аккаунта при необходимости нажмите GPS ещё раз. Две выбранные точки получают дорожный маршрут Geoapify.

Войти существующей назначенной тестовой учётной записью. Supabase — прежний изолированный тестовый проект, внутри только публичная клиентская конфигурация. Ключ Geoapify отдельно на телефоне, в APK отсутствует. Роли, база, заставка и launcher icon не менялись. Заказ/рабочая линия/Push ещё не подключены.

Проверки: Flutter analyze без замечаний; 409 Flutter-проверок (полный прогон и отдельный повтор шести обновлённых сценариев), 12 Android GPS-тестов. Проверены сам APK, ARM64/manifest, версия, сертификат, SHA-256, наличие kernel и конфигурации, отсутствие серверных ключей. Метаданные — verification.json, исходники — SOURCE_COMMIT.txt.

На телефоне проверить номера домов и читаемость карты, оба поля с клавиатурой/поворотом, обратный адрес точки и отмену, фактический GPS и дорожный маршрут. Показанные previews используют искусственные тайлы и маршрут; качество реального Geoapify и GPS на Tecno пока ждёт проверки владельцем. Отсутствующие в OSM дома не выдумываются.
