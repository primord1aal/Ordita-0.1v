## Установка

1. Скачать APK и сверить SHA-256.
2. Если установлена ранее выданная 0.5.7+9, подпись та же, versionCode повышен: открыть файл штатным установщиком и обновить поверх. Для согласованного USB-устройства: `adb install -r ORBITA-0.5.8+10-arm64-debug.apk`.
3. При отказе подписи/версии сохранить сообщение ошибки. Старое приложение и его данные не удалять, понижение версии не принуждать.

## Проверка владельцем

1. Холодный запуск в системных светлой и тёмной темах: правильный фирменный знак и фон, без старой салатовой заставки. Версия приложения — 0.5.8 / сборка 10.
2. Ввести данные существующего тестового пассажира и войти. После серверной проверки должен открыться пассажирский экран с картой и адресами.
3. Выйти, войти существующим тестовым водителем. Должен открыться экран «Линия» с вкладками «Поездки» и «Профиль». Роль назначает сервер. Настоящая линия остаётся отключённой в согласованном объёме.
4. Проверить выход, повторный вход и восстановление сессии после перезапуска. При проблеме передать текст ошибки и снимок без паролей или токенов.
